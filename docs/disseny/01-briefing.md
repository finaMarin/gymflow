# Briefing de GymFlow

## Client
Club Esportiu Turó, gimnàs de barri amb 1.200 socis, 3 sales i 40 classes dirigides setmanals.

## Problema actual
Les reserves es fan per telèfon i en un full de càlcul. Hi ha classes plenes amb gent que no es presenta.

## Objectius del producte
1. Reduir un 30% les places buides a les classes dirigides en els primers tres mesos.
2. Aconseguir que el 80% de les reserves i anul·lacions es facin via web, reduint les trucades a recepció.
3. Disminuir a menys de 2 minuts el temps necessari per donar d'alta un nou soci al sistema.

## Públic objectiu
El sistema té dos perfils d'usuaris diferents:
- GymFlow Recepció: adreçat al personal d'atenció al client i administració del club, que treballen des d'ordinadors d'escriptori.
- GymFlow Soci: adreçat als usuaris del gimnàs (com estudiants, gent gran o treballadors actius), dissenyat principalment per a telèfons mòbils.

## Requisits funcionals
Recepció:
1. Donar d'alta, editar i gestionar les fitxes dels socis.
2. Gestionar el calendari de classes dirigides i l'ocupació de les sales.
3. Validar i controlar l'accés dels socis a les instal·lacions.
4. Consultar l'estat dels pagaments i les quotes dels usuaris.

Soci:
1. Reservar plaça a les classes dirigides des de qualsevol lloc.
2. Anul·lar una reserva activa amb un sol clic.
3. Consultar la rutina d'entrenament diària personalitzada.
4. Visualitzar l'historial d'assistència i el progrés personal.

## Restriccions
Accessibilitat WCAG 2.2 AA, funcionament en mòbil, idioma català (amb previsió per al castellà i l'anglès).

## Funcionalitats futures
Exportar informes en PDF, ajuda contextual, mode entrenament amb veu i càmera.
